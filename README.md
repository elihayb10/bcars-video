# bcars-video

סרטוני מודעה לרכבים של בית הרכב (עפולה), נבנים אוטומטית מתמונות הרכב ומנתוני האתר bcars.co.il.

- `jobs/<plate>.json`: משימה לרכב (נכתבת ע"י מכונת המלאי).
- `render.mjs`: בונה סרטון מהמשימה עם התבנית `template/`.
- `videos/<plate>.mp4`: הסרטון המוכן. מטא מושכת אותו מהקישור הציבורי.
